The hard part of interrupted coding work is not reopening the repo. It is figuring out what the current state means and what to do next.

How it works

Return with enough context to decide.

StateCarry keeps the ordinary return path focused on the decision in front of you, with deeper context available when it changes that decision.

Built from current project state

Your project state stays inspectable.

StateCarry combines bounded observations from project files and Git with optional selected Codex conversations. The prepared overview stays separate from original records and from your acceptance.

Download

Download the StateCarry public beta for macOS.

StateCarry runs locally and keeps its project data on your Mac. The current public beta is available for Apple Silicon. You can also review the source and setup docs on GitHub.

Current v0.1.8 builds are Developer ID signed but not Apple-notarized, so macOS may ask you to confirm opening StateCarry from Finder.
